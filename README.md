# PPT 演示文稿

生成 PowerPoint 演示文稿，支持版式、图表与讲稿。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/pptx-generator#v1.0.3 --skill pptx-generator
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill pptx-generator
```

## 内容

技能正文在 `skills/pptx-generator/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/pptx-generator/payload/`，不要反向同步。版本以 git tag 为准。
